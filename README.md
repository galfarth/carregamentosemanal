# Programacao de Carregamentos - Eleva Quimica

Dashboard estatico para consulta e acompanhamento da programacao semanal de carregamentos da Eleva Quimica.

## Destaques

- Filtros por semana, ano, mes, data, produto, tipo e embalagem.
- Indicadores de volume, mix de carregamento, produtos, embalagens e media diaria.
- Graficos de volume por tipo, embalagem, produto e data/semana.
- Detalhamento por cota com busca e visual responsivo.
- Dados de demonstracao para uso quando a planilha externa nao estiver configurada.

## Como Rodar

Abra `index.html` diretamente no navegador. O projeto e 100% estatico e nao exige build.

## Estrutura

- `index.html`: pagina principal pronta para publicacao em GitHub Pages.
- `carregamentosemanal.html`: copia de trabalho com a mesma experiencia da pagina principal.
- `.gitignore`: arquivos locais ignorados pelo Git.

## Publicacao

Recomendado para portfolio: GitHub Pages com deploy a partir da branch `main` e pasta raiz.
